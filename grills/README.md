# Implementation Plans

Each file here is an implementation plan produced by the **grill-spec** skill.
A feature goes through these states:

- **Draft** — initial plan, needs review
- **Approved** — reviewed and accepted, ready for implementation
- **In Progress** — being worked on
- **Done** — implemented and verified

## Naming

Files are named using kebab-case: `<feature-name>.md`.

## Workflow

1. User provides a feature idea → skill grills for details
2. Plan saved as **Draft** → user reviews and approves
3. Plan marked **Approved** → implementation begins
4. Implementation done → plan marked **Done**
